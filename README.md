# llm-morph-parsing
Investigating how LLMs incrementally resolve Turkish morphological parsing ambiguities through probing, attention analysis, and causal interventions.


## Overview

This project studies how transformer language models process Turkish morphological parsing ambiguities online and incrementally.

The main goal is to investigate whether LLMs behave more like:
- serial parsers that commit early and revise later,
- uncertainty-maintaining probabilistic parsers,
- or noisy prior-driven parsers.
